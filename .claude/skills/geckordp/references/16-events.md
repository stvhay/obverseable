# Events Enum

```python
from geckordp.actors.events import Events
```

All event types for `add_event_listener()`.

`TAB_LIST_CHANGED`, `WORKER_LIST_CHANGED`, `ADDON_LIST_CHANGED`, `SERVICE_WORKER_REGISTRATION_LIST_CHANGED`, `PROCESS_LIST_CHANGED`, `FORWARDING_CANCELLED`

`PAUSED`, `RESUMED`, `WILL_INTERRUPT`, `NEW_SOURCE`

`EVALUATION_RESULT`, `FILE_ACTIVITY`, `PAGE_ERROR`, `LOG_MESSAGE`, `CONSOLE_API_CALL`, `REFLOW_ACTIVITY`, `NETWORK_EVENT`, `INSPECT_OBJECT`, `LAST_PRIVATE_CONTEXT_EXITED`, `DOCUMENT_EVENT`
